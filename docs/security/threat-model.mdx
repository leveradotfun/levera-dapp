## Trusted roles

| Role | Powers | Failure |
|---|---|---|
| Earn Pool `owner` | `setFactory`, `setGuardian`, `unpause`, two-step `transferOwnership`, lockup knobs (retired, no effect on transfers) | Compromised EOA used to be a one-tx drain via `registerPool`. That path is factory-only now. Owner can still pause/unpause and replace the factory pointer — **multisig + timelock in production**. |
| Earn Pool `guardian` | `pause` only | Can halt pairing, protect, harvest, mint. Cannot unpause, cannot move cash. Set to a distinct multisig. |
| Factory `owner` | `setProtocolFeeRecipient` | Fee address only. Cannot register pools except by deploying clones through `createLaunch`. |
| Launch `creator` | Fee-denomination toggle is immutable at create. Claims creator ETH fees. | Cannot attach/detach 2x after launch. |
| Keepers | Permissionless: `graduate`, `tryPair`, `fillSellRoute`, `fillBuyRoute`, `netSeniorBetween`, `rebalanceToReserve`, `harvest`, `accruePools` | Liveness assumption: if keepers stop, occupancy is still owed, harvest fees sit uncounted, coins can sit out of band. Anyone can call the same functions. |
| Oracle | Single ETH/USD (+ USDG/USD) feed, 25 h freshness matching Robinhood's 24 h heartbeat, 2% confidence cap | Stale/wide feed **fail-closes** (reverts). A *fresh but wrong* price moves leverage, protect size, minOut, funding together. No second feed yet. |
| Swap venue (`ISwapRouter`) | Every ETH$\leftrightarrow$USDG conversion | Production: `OracleSwapRouter` (oracle fill) or a real AMM. **Not** `MockSwapRouter` (Ownable, can skew, 0 fees). 1% `SWAP_TOLERANCE_WAD` bricks rather than fills a skewed venue. On a real AMM the same 1% is a sandwich ceiling — add deadlines / private relay before mainnet money. |

## Not trusted

- Meme traders, HFyc holders, launch bots, any EOA that is not owner/guardian.
- `recentVolumeUsd` ranking (single-slot wash detector). `reallocateFrom` moves real senior on that score. Two-wallet wash can still game it; treat ranking as adversarial.

## Failure modes we accept

- **ETH −50% one oracle print:** junior wipes, HFyc is leftover / supply. 2x first-loss. Named, not a bug.
- **Keeper lag:** protect is 15% of vault per tx; $L$ can print above 2.5 between ticks.
- **Pause:** mint/pair/protect/harvest halt. Curve/AMM buys and HFyc redeem stay up so people can exit. Redemption is paid in kind and does not depend on a route or a swap, so it keeps working while paused.

## Perimeter that was tightened

- CEI on curve buy (refund after state writes).
- `ISwapRouter` not `MockSwapRouter` in Launch/EarnPool.
- Factory-only `registerPool`.
- Two-step HFyc owner.
- Guardian pause.
- `MIN_RAISE_ETH = 0.1 ether`.
- `occupancyCursor` 32-pool rotate on redeem.
- WETH `safeTransfer`.
- 1x cannot take creator fees in HFyc.
- Capped AMM sells re-derive $k$ from ETH actually paid.

## Before mainnet with real money

External audit + bounty sized to TVL. The senior-in-$k$ / vault-not-in-AMM layout is not a standard auditor pattern. The invariant suite is the cheapest way to make that audit short.
