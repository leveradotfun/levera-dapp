1x pays 30 / 95 / 0: it never rents senior, so its tape does not lift the Earn Pool.

## Occupancy

| Parameter | Value |
|---|---|
| $r_0$ | 2% APR |
| $r_1$ | 8% (so 10% at $U^\star$) |
| $r_2$ | 60% (so 70% at $U = 1$) |
| $U^\star$ | 80% |
| Off | $L \ge 2.5$ or unpaired |

The rate prices scarcity rather than being a constant: 10% APR is what a healthily-utilised book pays.

## Leverage surcharge

Charged on top of the flat 125 bps, and paid into the AMM reserve as cushion rather than to any fee
stream.

| Parameter | Value |
|---|---|
| At target | 0 |
| At an edge ($L = 1.5$ or $2.5$) | 250 bps |
| Cover surcharge max | 400 bps at $\mathrm{CR}_{\mathrm{global}} \le 1$, exits only |
| Comfort CR | $1.5$ |
| All-in ceiling | 700 bps |
