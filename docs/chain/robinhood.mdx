## Fork notes

- Wipe reverts an `evm_snapshot` taken at fork start. `anvil_reset([])` empties the fork.
- `CREATE` / new-wallet `estimateGas` on Nitro can fail with `metadata is not found`. Skip estimate; `anvil_setBalance` after touching 1 wei (32-byte hex).
- Mock USDG/WETH in the fork are 18-dec mintable. Live USDG is 6-dec.
- Bot funding on the fork is large (10M USDG / 10k ETH / 10k WETH) so load ticks are not gas-starved.

## Apps default
