`ui/` is the operator console (`npm run dev` $\to$ port **3001**). Deploy is always a tab.

## Jobs

- **Deploy / wipe.** Wipe = revert the Anvil snapshot taken at fork start. Not `anvil_reset`.
- **Launch bots.** Mix 1x and 2x. 1x must not be tagged `[HFyc fees]` unless `leverageEnabled && creatorFeeInHfyc` (the tag used to follow the config flag alone).
- **Trader bots.** Curve slippage 3%, AMM 15% + retry. Post-grad quotes use AMM $k$, not NAV mint/redeem.
- **Loop / simulate.** Load ticks 80–150 ms. Fork bot funding is oversized on purpose.
- **Keeper.** Harvest, accrue occupancy, correct reserve cover, sweep orphans. On a research fork it also acts as the counterparty on open [rebalance routes](/protocol/routes), looping fills until the pool is back inside the band or the per-fill cap binds — in production that is an arbitrageur, not the console.
- **Collateral shock.** Drives the oracle so leverage can be measured. Step, grind, sine round trip and gap presets; every research row is stamped with the offset and the path id. Without it the fork's feed is frozen and every attribution column divides by zero.
- **Research files.** Sweeps the whole book every 30s into `data/book.csv` and `data/pools.csv`, one pool row per registered launch, plus discrete rows into `data/events.csv`. See [Research files](/apps/csv).

Human launches from the public app redirect to `/coin/:address` immediately so you can keep wiping from `/ui` without a stale-state banner.
